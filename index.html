// 03 · Scheduling · Go · Kubernetes

I'm the lead contributor of Cortex, the scheduler that decides where SAP's virtual machines run.

I built this Kubernetes operator from the ground up. It makes smart placement decisions for OpenStack compute, storage and networking, and even gang-schedules GPU workloads on Kubernetes.

More

Cortex covers OpenStack compute (Nova), storage (Cinder, Manila) and networking (Neutron). I shaped its core: a knowledge database that ingests metrics and other data sources, and a scheduler built on Kubernetes-native inventory like VM and hypervisor CRDs. Today, Cortex gives SAP Cloud Infrastructure capabilities it never had before: automated failover partitioning and reservations, committed-resource scheduling, and capacity planning through an infrastructure dashboard.
